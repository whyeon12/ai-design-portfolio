01

CAD MCP

단선도에서 회로도 · 표지 · VP 수정까지, AutoCAD 도면을 AI가 직접 읽고 고친다.

  • 단선도 → 토폴로지 — 모선 · 베이 · 기기 연결을 읽어 베이 구성표를 자동으로
  • 회로도 구성 · 인터록 — 없는 기기 시트를 빼고 번호를 다시 매기며, 인터록 접점 조건을 검산
  • 세 번 확인 — 실측 · 저장 전 검산 · 출력본 눈검증 뒤에만 저장
  • 표제란 · 표지 · 합본 — 제출 목록 한 장에서 도번 · 제목 · 매수를 채우고 한 권으로
  • VP 코멘트 수정 — 고객 코멘트를 판정별로 나누고, 구름 · △ 표기, 수정 차수 저장, 전 · 후 합본
  • 실수는 한 번만 — 사고 기록이 코드 검사가 되어 다음 작업을 지킨다
02

사양검토 AI

입찰 기술규격서 수천 쪽을 읽고, 근거 쪽이 붙은 검토보고서와 독소조항 판정을 만든다.

  • 받은 자료 전부 — 규격서 · 물량표 · 계약조건 · 단선도 · 현장 사진 · 메일을 함께 읽음
  • 검토보고서 6개 절 — 공급 스코프 · 사양 · 문서 간 불일치 · 공급 조건 · 독소조항 · 확인 필요, 모든 문장에 근거 쪽
  • 문서 간 불일치 — 규격서와 단선도 값이 다르면 바로 표시
  • 여러 단계 추론 — 사실 → 고객 기준 → 조건 → 요구 → 당사 능력 → 판정, 판정은 코드가
  • 독소조항 · 네 가지 판정 — 심한 순 정렬, 참 · 거짓 · 모름 · 상충 (모르면 모른다고)
  • 견적 · Deviation · 질의서 — 결과가 바로 산출물로, 설계자 결정은 기록해 다음 입찰에 재사용
